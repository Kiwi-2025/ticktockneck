# 脖子活动提醒（TickTockNeck）

一款基于 Electron 的小巧桌面提醒工具，番茄钟式地提醒你在长时间工作、学习后活动脖子、缓解颈椎疲劳。休息时会自动播放一段颈部活动操演示视频，跟着做即可。

> 适用人群：久坐办公、长时间低头使用电脑 / 手机的人群。

---

## 一、为什么要关心颈椎？

### 颈椎病的危害

颈椎病（cervical spondylosis）是颈椎间盘退行性病变及其继发改变刺激或压迫邻近组织（神经根、脊髓、椎动脉、交感神经等）引起的一系列症状。它的危害往往被低估：

- **颈肩疼痛与僵硬**：反复发作的颈肩部酸痛、僵硬，影响活动度。
- **上肢症状**：放射性疼痛、手指麻木、握力下降，严重时影响写字、拿物。
- **头晕头痛**：椎动脉受刺激导致供血不足，引起眩晕、头痛，甚至恶心、猝倒。
- **睡眠与情绪**：长期疼痛影响睡眠质量，继而引发焦虑、烦躁、注意力下降。
- **严重并发症**：脊髓型颈椎病可致下肢无力、行走不稳、踩棉花感，甚至大小便障碍，可能需要手术干预。
- **生活质量下降**：长期慢性不适显著降低工作与生活品质。

### 颈椎病的成因

颈椎病正呈现年轻化趋势，与现代生活方式密切相关：

- **长时间低头**：玩手机、看平板时头部前倾，颈椎承受数倍于头重的压力（"低头族"）。
- **久坐不动**：长时间伏案工作、打游戏，颈部肌肉持续紧张得不到放松。
- **姿势不良**：含胸驼背、头前伸、桌椅高度不合适、显示器位置过低。
- **退行性改变**：随年龄增长，椎间盘水分减少、弹性下降，是自然老化过程。
- **睡眠姿势不当**：枕头过高 / 过低 / 不贴合颈部曲线，睡姿扭曲。
- **受寒与外伤**：颈部受凉使肌肉痉挛；急刹车、运动损伤等外力也可能诱发。
- **缺乏锻炼**：颈肩部肌肉力量薄弱，难以稳定颈椎、分担负荷。

> 本应用面向的是**姿势性、劳损性**颈肩不适的日常预防与缓解。若已出现持续麻木、无力、眩晕、行走不稳等症状，请及时就医，不要仅靠做操自行处理。

## 二、如何通过做操缓解

颈部保健操的核心思路是：**定时中断静态姿势、缓慢活动颈椎、放松并强化颈肩肌肉**。关键是"定时 + 缓慢 + 适度"，而非追求大角度。

### 推荐的颈部活动操

以下是一组经典的颈部保健动作（本应用内置的 5 段演示视频即围绕此类动作）：

1. **颈部前屈后伸**：缓慢低头至下巴尽量贴近胸口，再缓慢仰头看向天花板。
2. **颈部侧屈**：耳朵缓慢向同侧肩膀靠拢，左右交替。
3. **颈部旋转**：头部缓慢向左转看向左肩后方，再向右转，动作柔和。
4. **耸肩缩颈**：双肩上提靠近耳朵、停顿，再缓慢放下，放松颈肩。
5. **扩胸夹背 / 米字操**：以头部缓慢画"米"字轨迹，或做扩胸、肩胛骨后缩动作。

### 做操要点

- **频率**：建议每工作 **30 分钟**左右活动一次（正是本应用的默认活动时长）。
- **幅度**：以感到牵拉、微微酸胀为宜，**切勿快速甩头、猛力扭转**，以免损伤。
- **节奏**：每个动作缓慢匀速，配合呼吸。
- **时长**：每次活动 **2 分钟**左右即可（本应用默认休息时长）。
- **持之以恒**：预防颈椎病贵在日常坚持，而非偶尔大强度锻炼。

> 急性发作期（剧痛、明显活动受限）应**停止活动操、及时就医**，不要强行做操。

## 三、本应用如何帮你

TickTockNeck 把"定时 + 做操"自动化，免去你自觉性不足的问题：

- **番茄钟式循环**：默认 30 分钟活动期 → 2 分钟休息期，循环往复。
- **休息弹窗**：休息开始时屏幕右上角弹出提醒窗口，**自动循环播放 5 段颈部活动操演示视频**，每段播放一遍，动作之间留出停顿，跟着屏幕做即可。
- **可调节**：活动时长、休息时长可在主窗口设置（休息时长最小 2 分钟）。
- **轻量常驻**：最小化后驻留系统托盘，不占桌面，到点自动唤醒。
- **自动播放**：休息时自动循环播放颈部活动操演示视频，无需手动操作。

### 使用方法

1. 启动程序后，设置"活动时间"与"休息时间"（分钟）。
2. 点击"开始 / 继续"，进入活动倒计时。
3. 倒计时归零，休息弹窗自动弹出并播放活动操视频，跟着做。
4. 休息结束自动关闭弹窗，进入下一轮活动；也可点击"知道了"提前结束休息。

## 四、下载与构建

### 方式一：直接使用打包版

在 [Releases](../../releases) 页面下载最新的 `ticktockneck 1.1.2.exe`（Windows 便携版，免安装，双击即用）。

### 方式二：自行构建

环境要求：Node.js（建议 18+）。

```bash
# 安装依赖
npm install

# 开发运行
npm start

# 运行测试
npm test

# 打包为 Windows 便携 exe（输出到 dist/）
npm run dist
```

打包产物位于 `dist/` 目录下。

关于图标：`logo.jpg` 是运行时图标素材，启动时自动裁剪成方形时钟图案（托盘 32px、主窗口 256px）；`build/icon.png`（256px，由 `logo.jpg` 同样裁剪而来）在打包时嵌入 exe，作为文件图标。首次 `npm run dist` 需联网下载 electron-builder 的 `winCodeSign` 工具链（用于写入 exe 图标），国内网络可加镜像：
`$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://registry.npmmirror.com/-/binary/electron-builder-binaries/"`

## 五、技术栈与结构

- **Electron** 桌面框架
- **原生 Node.js 测试**（`node --test`）

关键文件：

| 文件 | 作用 |
|------|------|
| `main.js` | 主进程：窗口、托盘、计时、IPC |
| `lib/timer.js` | 计时状态机（活动 / 休息循环） |
| `lib/icon.js` | 图标缺失时兜底生成纯色 PNG 图标 |
| `logo.jpg` | 托盘 / 窗口图标素材（自动裁剪成方形时钟图案） |
| `build/icon.png` | exe 文件图标素材（256px，打包时嵌入 exe） |
| `preload.js` | 上下文隔离桥接（`window.api`） |
| `index.html` / `renderer.js` / `styles.css` | 主控制窗口 |
| `reminder.html` / `reminder.js` | 休息弹窗（视频循环播放） |
| `gif/` | 5 段活动操演示视频（`action-1..5.mp4`） |
